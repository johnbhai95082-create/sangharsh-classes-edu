# Sangharsh Classes - Updated Website

## Files
- `index.html`: Homepage; each Class 6-12 card opens its own page.
- `class-6.html` ... `class-12.html`: separate class dashboards.
- `style.css`: shared responsive styling.

## Publish on GitHub Pages
1. Download and unzip this package.
2. Open your GitHub repository: https://github.com/johnbhai95082-create/sangharsh-classes-edu
3. Upload/replace `index.html` and `style.css`.
4. Upload all seven `class-N.html` files to the repository root.
5. Commit changes. GitHub Pages will publish the changes automatically.

Login has been removed from this new homepage and class pages.

Important: This is the working page structure. Actual chapter notes, PDF files, questions and MCQ banks still need to be added to each subject section.
